# 简历生成器模块设计文档

## 1. 模块概述

### 1.1 功能定位
简历生成器是 Future Helios 工具箱中的第十三个核心模块，旨在帮助用户快速创建专业、美观的个人简历。模块提供可视化编辑、实时预览、多模板切换、多格式导出等完整功能。

### 1.2 核心价值
- **零成本**：纯前端实现，无需注册、无需付费
- **多模板**：4 套精心设计的简历模板，覆盖不同行业场景
- **实时预览**：编辑即所见，所见即所得
- **多格式导出**：支持 PDF、Markdown、JSON 三种格式
- **数据持久化**：自动保存到 localStorage，刷新不丢失

## 2. 功能需求

### 2.1 简历内容模块

| 模块 | 字段 | 说明 |
|------|------|------|
| 个人信息 | 姓名、职位、邮箱、电话、地址、网站、GitHub、LinkedIn | 基础联系方式 |
| 个人简介 | 一段文字 | 30-100字自我介绍 |
| 教育背景 | 学校、专业、学历、起止时间、描述 | 支持多条记录 |
| 工作经历 | 公司、职位、起止时间、描述 | 支持多条记录，描述支持多行 |
| 项目经验 | 项目名、角色、链接、起止时间、描述 | 支持多条记录 |
| 专业技能 | 分类名、技能列表 | 支持多个分类，技能支持等级 |
| 获奖证书 | 名称、颁发机构、日期、描述 | 支持多条记录 |
| 语言能力 | 语言、熟练度 | 支持多条记录 |

### 2.2 模板系统

#### 模板一：现代简约（Modern）
- 左侧边栏 + 右侧主内容的双栏布局
- 侧边栏深色背景，含联系方式、技能、语言
- 主内容区白色背景，含经历、项目
- 适合互联网、科技行业

#### 模板二：经典商务（Classic）
- 单栏居中布局
- 顶部姓名大字标题，下方分隔线
- 传统时间轴式经历展示
- 适合金融、教育、政府行业

#### 模板三：极简风格（Minimal）
- 单栏左对齐布局
- 大量留白，字号对比强烈
- 无装饰线条，仅用空白分隔
- 适合设计、创意行业

#### 模板四：创意双色（Creative）
- 顶部彩色横幅含姓名职位
- 双栏内容区，紧凑排布
- 技能用进度条可视化
- 适合营销、广告行业

### 2.3 导出功能

| 格式 | 实现 | 用途 |
|------|------|------|
| PDF | window.print() + 打印样式 | 正式投递 |
| Markdown | 生成 .md 文本，复制或下载 | 在线发布 |
| JSON | 序列化数据结构 | 数据备份/迁移 |

### 2.4 辅助功能

- **示例数据**：一键填充演示数据，快速体验
- **自动保存**：每次修改自动存入 localStorage
- **主题色**：4 套模板各自支持自定义主色
- **字号调节**：紧凑/标准/宽松三种行距
- **空字段隐藏**：未填写的字段自动不显示

## 3. 技术设计

### 3.1 文件结构

```
src/
├── views/
│   └── ResumeGenerator.vue       # 主视图
├── utils/
│   └── resumeTemplates.ts        # 模板渲染逻辑 + 类型定义
└── router/
    └── index.ts                  # 添加 /resume-generator 路由
```

### 3.2 数据结构

```typescript
interface ResumeData {
  personal: {
    name: string
    title: string           // 职位/头衔
    email: string
    phone: string
    location: string
    website: string
    github: string
    linkedin: string
    summary: string         // 个人简介
  }
  education: EducationItem[]
  experience: ExperienceItem[]
  projects: ProjectItem[]
  skills: SkillCategory[]
  certifications: CertItem[]
  languages: LanguageItem[]
}
```

### 3.3 技术选型

- **PDF 导出**：使用浏览器原生 `window.print()` + `@media print` 样式，保证矢量清晰、文字可选
- **Markdown 导出**：字符串模板拼接，支持复制到剪贴板和下载文件
- **JSON 导出**：`JSON.stringify` + Blob 下载
- **数据存储**：`localStorage` 键名 `resume_generator_data`
- **图标库**：lucide-vue-next

## 4. 交互设计

### 4.1 编辑区
- 使用折叠面板（Accordion）组织各模块
- 每条记录支持上移/下移/删除/复制
- 空字段标记为"选填"，降低用户压力
- 输入框失焦后实时更新预览

### 4.2 预览区
- A4 比例展示（210mm × 297mm）
- 白色纸张 + 阴影，模拟真实纸张
- 模板切换有过渡动画
- 可缩放查看（50% / 75% / 100%）

### 4.3 导出
- PDF：调用 `window.print()`，用户选择"另存为 PDF"
- Markdown：弹窗显示，支持复制和下载
- JSON：直接下载文件

## 5. 样式规范

### 5.1 颜色变量
- 主背景：`--bg-primary: #0f0f23`
- 卡片背景：`--bg-secondary: #1a1a2e`
- 玻璃效果：`.glass` 类
- 渐变文字：`.gradient-text` 类

### 5.2 简历纸张
- 宽度：210mm（A4）
- 内边距：根据模板调整（15-25mm）
- 字体：`'Inter', 'Noto Sans SC', sans-serif`
- 正文字号：14px
- 标题字号：根据模板 24-32px
